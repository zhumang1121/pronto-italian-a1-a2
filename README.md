# Pronto! 意大利语 A1/A2 学习站

一个面向中文初学者的意大利语学习网站，把课堂笔记变成可以每天背、每天练、自动复习的学习工具。尤其适合 **Bocconi 意大利语 A1/A2 课程学生**复习课堂内容、准备考试，也适合希望在**一个月内集中打基础**、为意大利生活和旅游做准备的人。

项目针对已提供的课堂笔记和往年听力文稿逐项整理，尽量做到学习内容与这些备考资料精准对应。这里的“对齐考试”指对齐本项目所获材料；不同学期的考试范围和题型仍以老师当期要求为准。

## 下载和开始

**Mac 用户推荐：[下载完整学习包](Pronto-自动保存版.zip?raw=true)。** 下载后解压，双击其中的 `Pronto学习.app`，浏览器会自动打开学习站。需要安装 Python 3.9 或更新版本；无需安装前端依赖，也不需要填写 API Key。

也可以下载或克隆整个仓库，从仓库根目录启动：

```bash
python3 server.py --open
```

Windows 可在已安装 Python 的终端中运行：

```powershell
py -3 server.py --open
```

这种终端启动方式需要在学习时保留终端窗口。Mac 完整包中的应用和 `开始学习.command` 会在后台启动服务，启动窗口可以关闭。Windows 和 Linux 使用同一份 Python 服务和网页代码，但未提供独立的桌面安装包。

本机地址为 **http://127.0.0.1:8768**。下次学习，重新打开应用即可；不要只打开 `dist/index.html`，否则不会启动自动保存服务。

## 适合谁

- **Bocconi 意大利语 A1/A2 学生**：把分散的课堂笔记串成单元，集中练词汇、语法、听写和往年听力文稿。
- **只有一点多邻国基础的初学者**：中文讲解从发音、自我介绍开始，逐步进入句子结构、变位和时态。
- **准备在意大利生活、交换或旅游的人**：练习点餐、购物、问路、交通、住宿、日期、天气和日常交流。
- **希望一个月集中学习的人**：按自己的节奏选择 Unit，每天先复习，再学新词、读一节语法并进行输出练习。

## 内容如何对应备考资料

课堂笔记共 29 页，整理为 17 个学习单元。重复出现的词合并来源页码；常规复数、阴阳性词尾和人称变位放在词条说明与语法表中，避免把每一种规则词形都变成重复词卡。

课程从字母和发音、自我介绍出发，涵盖疑问句、名词与冠词、形容词配合、现在时、介词和缩合介词、物主词、部分冠词、情态动词、piacere/mancare、数字与时间、反身动词、近过去时、一般将来时、直接宾语代词、家庭与书信等内容，并结合生活场景练习。

例句和自测为教学重新编写，来源页码指对应的词或知识点，不表示所有例句逐字出自笔记。往年听力文稿的明显笔误已校订，全部改动和原稿摘录可在每篇下方查看；无法从原音频确认的修复明确标为“上下文推测”。

详细记录见 [内容核对说明](内容核对说明.md) 和 [词根记忆校核](词根记忆校核.md)。

## 一个月怎么学

每天可以安排约 60–120 分钟，结合自己的基础调整：先完成到期复习，再学 25–40 个新词，理解一节语法，最后做听写或精听。

| 阶段 | 建议重点 |
| --- | --- |
| 第 1 周 | Unit 1–4：发音、自我介绍、基础句子、冠词、现在时与描述 |
| 第 2 周 | Unit 5–9：地点、吃喝、购物、情态动词、问路与交通 |
| 第 3 周 | Unit 10–14：数字钟点、住宿、日常动作、近过去时和将来计划 |
| 第 4 周 | Unit 15–17、薄弱语法、全局复习与五篇听力；结合老师要求做综合检查 |

这些是学习建议，网站不会因为日期而锁住单元。目标是持续积累能听懂、说出和写出的基础表达，学习速度取决于每天的投入和已有基础。

## 熟悉度和复习规则

| 本次评分 | 下次出现 | 今天是否过关 |
| --- | --- | --- |
| 不认识 / 模糊 | 再评分 10 张其他词卡后；无其他词可出时立即重现 | 否，直到改选认识或很熟 |
| 认识 | 次日 | 是 |
| 很熟 | 评分日期 +7 天 | 是 |

原本不认识的词，后来选了“认识”，就从这次认出的日期起安排次日复习。日期统一按意大利时间计算；新一天打开网站，首页与“复习”自动更新。

## 分享后会不会混进度

**不会跨电脑混进度。** GitHub 分享的是程序与学习材料，不包含维护者的学习数据库。

每台电脑在当前系统用户的 `~/Documents/Codex/ProntoLearning/data/` 下独立保存进度。SQLite 是主要存储，浏览器的本地缓存用于缓冲中断时的待保存操作。网站更新、刷新和换浏览器，不需要重新导入进度；暂不提供跨设备云同步。

同一台电脑、同一个系统用户启动多份程序，会使用同一份默认进度。若需要另建独立学习档案，可指定另一个数据目录和端口：

```bash
python3 server.py --open --port 8770 --data-dir ./my-progress
```

`.gitignore` 已排除数据库、日志、备份、缓存和本地进度文件。请分享本仓库或完整学习包。

## 构成与设计

项目采用 **原生 HTML、CSS、JavaScript + Python 标准库 + SQLite**。页面、词库、语法、音频都随程序提供，无需前端构建；运行时不依赖模型服务。

```text
README.md                  项目介绍与使用说明
server.py                  本机服务、事务保存、音频范围请求
开始学习.command           Mac 备用启动入口
dist/
  index.html / styles.css  页面与响应式界面
  app.js                   单元、词卡、语法和听写交互
  vocabulary.js            课堂词库与例句
  lessons.js               语法讲解和自测
  curriculum.js            单元编排、校订记录与参考来源
  roots.js                 词根、构词与词族记忆
  learning-core.js          复习规则和进度恢复
  progress-store.js         自动保存与中断缓冲
  listening.js             音频播放、循环、定位和查词
  listening-data.js        中意文稿、校订记录及时间轴
  audio/                  五篇已生成的音频
Pronto-自动保存版.zip       包含 Mac 应用的完整学习包
```

设计围绕一条学习路径：**选单元 → 理解 → 记忆 → 输出 → 到期复习**。中文释义按需展开，鼓励先回忆；听力中先听后看，允许只显示自己需要的文本；熟悉度只需一次选择，复习日期由程序负责。

课堂词条使用稳定的意大利语 ID，相同词跨单元共享记录；保存操作按唯一编号去重，避免重试造成重复评分。本机服务仅监听 `127.0.0.1`，学习数据库与程序文件分开。
